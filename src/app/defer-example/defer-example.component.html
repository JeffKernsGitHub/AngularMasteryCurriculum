Angular Deferrable Views (@defer)

Lazily load component chunks and template subtrees on-demand using declarative triggers.

@defer (on hover)

1. Hover Trigger

Move your cursor over the button to download and render the deferred component.

@defer (on hover(hoverBtn)) { } @placeholder {
💤 Waiting for hover trigger...
} @loading (minimum 800ms) {
Downloading deferred component chunk...
} @error {
⚠️ Failed to load deferred bundle.
}
@defer (on interaction)

2. Interaction Trigger (Click / Focus)

Click the button below to initialize the deferred chunk.

@defer (on interaction(clickBtn)) { } @placeholder {
💤 Waiting for click interaction...
} @loading (minimum 800ms) {
Downloading deferred component chunk...
} @error {
⚠️ Failed to load deferred bundle.
}
@defer (when condition)

3. Programmatic Signal Trigger

Triggers when the isTriggered() signal evaluates to true.

@defer (when isTriggered()) { } @placeholder {
💤 Waiting for Signal state change...
} @loading (minimum 800ms) {
Downloading deferred component chunk...
} @error {
⚠️ Failed to load deferred bundle.
}
@defer (on viewport)

4. Viewport Scroll Trigger

Scroll down into the viewport to trigger IntersectionObserver loading.

@defer (on viewport) { } @placeholder (minimum 500ms) {
📜 Scroll down: This placeholder triggers loading once visible in viewport.
} @loading (minimum 800ms) {
Downloading deferred component chunk...
} @error {
⚠️ Failed to load deferred bundle.
}
