Angular Pipes Transformation Demo

Explore how built-in and custom pure pipes format data in templates without altering the underlying Signals state.

📅 1. Date Transformation Pipes

@let rawDate = currentDate();
Pipe Expression Transformed Output
currentDate() | date {{ rawDate | date }}
currentDate() | date:'short' {{ rawDate | date:'short' }}
currentDate() | date:'mediumDate' {{ rawDate | date:'mediumDate' }}
currentDate() | date:'fullDate' {{ rawDate | date:'fullDate' }}
currentDate() | customDate (Custom Pipe) {{ rawDate | customDate }}
currentDate() | customDate:'YYYY-MM-DD' {{ rawDate | customDate:'YYYY-MM-DD' }}

🔢 2. Number, Currency & Percentage Pipes

@let rawNum = someNumber(); @let rawPct = somePercentage();
Pipe Expression Transformed Output
someNumber() | number {{ rawNum | number }}
someNumber() | number:'1.2-2' {{ rawNum | number:'1.2-2' }}
someNumber() | currency:'USD':'symbol' {{ rawNum | currency:'USD':'symbol' }}
someNumber() | currency:'EUR':'symbol' {{ rawNum | currency:'EUR':'symbol' }}
somePercentage() | percent:'1.1-2' {{ rawPct | percent:'1.1-2' }}

🔤 3. String Case Transformation Pipes

@let textVal = someString();
Pipe Expression Transformed Output
someString() | uppercase {{ textVal | uppercase }}
someString() | lowercase {{ textVal | lowercase }}
someString() | titlecase {{ textVal | titlecase }}

📦 4. JSON Debugging Pipe

JsonPipe converts JavaScript objects to pretty-printed JSON strings for immediate template inspection. 

{{ someObject() | json }}
